12306 智能中转

直达与换乘方案混合展示，可排序/筛选/分页。异站换乘为同城车站（如福州/福州南），额外预留30分钟；已发车方案不提供实时查询；无当日数据时自动回退最近爬取数据按每日开行推算。勾选「城市范围」时，输入厦门即含厦门/厦门北/厦门高崎；勾选「在线模式」则搜索前自动联网抓取（联网数据优先并覆盖本地）。推荐先到「爬取数据 → 一键导入向导」一键导入两端数据，方案最全。

一键导入向导（推荐）

只需填出发地、到达地、日期，自动抓取 两端车站大屏 → 车次时刻表 → 直达余票 → 票价，全部合并入库（联网数据覆盖本地）。完成后直接到「换乘搜索」搜索即可，无需手动逐项导入。不勾选“完整导入”则只抓大屏+余票，更快但换乘方案较少。
